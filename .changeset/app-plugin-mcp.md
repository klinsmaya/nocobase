Add the MCP plugin: `/api/mcp` serves the application as an MCP server over Streamable HTTP. A request authenticates the way the command-line manifest does, with a session, an API key or a credential another plugin recognizes, and its tools are the read commands that caller may run, derived from the API document and sent through the application's own router with the caller's credential.
