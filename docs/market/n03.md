# N03 扫描、审核、不可变发布和撤销

N03 继续放在 `@nocobase/plugin-market-catalog`。租户中间件和 N02 的草稿 CAS 没有改语义。

## 标签

三个标签各写各的记录。

- 扫描写入 `marketScanReports`，并把发布行的 `scanned` / `scanPassed` 设上。扫描通过不会把 `humanReviewed` 设为真。
- 人工审核写入 `marketReviews`。审核人来自 `ctx.state.currentUser`。
- 发布者核验仍是 `marketPublishers.verificationStatus`。发布不会把它改成 `verified`。

## 发布内容

创建时计算 `sha256:` 摘要。客户端给出的摘要不一致则返回 400，不插入行。包字段来自 I02 的 plugin manifest。`license` 单独成列。样例是标准包 `notes` 和带 `com.example.agentmarket` 扩展的 `research-agent`。

`marketReleases:replace` 一律返回 409，不改摘要。已发布的内容不能原位改写。要改内容就新建一个 `releaseId`。

公开可见还要求最近一次审核的 `publicMaterial` 是 `template`、`synthetic` 或 `explicitly_allowed`。个人信息信号记在扫描报告里，不能代替这个审核标记。

## 撤销

`revoke` 要求原因，把状态写成 `revoked`，并写 `marketAuditEvents`。行还在。`distribute` 对已撤销发布返回 403。这个动作是分发闸门的占位，不删除发布，也没有消费端数据可删。

扫描在请求里完成，受体积、路径和解压倍数限制。这里没有接后台队列，也没有 `/market/v1`。
