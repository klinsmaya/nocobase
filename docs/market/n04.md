# N04 来源适配、同步队列和能力声明

N04 仍在 `@nocobase/plugin-market-catalog`。它只依赖 N02 的租户列和 I02 的能力状态。同步不发布 release，也不运行 Agent。

允许的适配器只有两个进程内桩。`fixture-catalog` 返回五条元数据。`fixture-pages` 返回三条，并把 `execution.multi_member` 标成 `unsupported`。没有外网请求，也没有模型调用。

`marketSyncJobs` 是队列记录。`run` 只处理 `kind=metadata-sync` 且状态为 `queued` 的作业。`kind=agent` 在创建时返回 400。作业带页大小、条数上限和超时。来源不可用、游标无效和超时都写在作业的 `errorCategory` / `errorCode` 上，失败时 `items` 为空。成功时写入 `nextCursor`，下一页用这个游标再排一个作业。

能力声明写在 `marketCapabilityDeclarations`。状态是 `supported`、`unsupported` 或 `unverified`。列表能直接看到不支持的能力。

作业按 `ncTenantId` 过滤。别的租户读不到，也不能替它执行。
